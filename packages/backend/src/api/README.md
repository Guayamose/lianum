# API y sesiones

`wallet/` contiene el cliente común y la sesión wrapped de wallet.
`accounts/` contiene las sesiones, HTTP y clientes de cuentas.
`claims/` contiene reclamaciones nativas y su variante `wrapped/`.
`withdrawals/` contiene revisión, admisión, release y reanudación de retiradas.
`transport/` contiene el transporte de lectura del propietario.

Las pruebas correspondientes están en `packages/backend/tests/api/`.
