# Interfaz web

`app.mjs` inicia la interfaz; `index.html` define la página y `style.css`
su apariencia. `state/` contiene el modelo que decide qué se muestra.

| Función en features/ | Contenido |
| --- | --- |
| `accounts/` | Revisión del grafo y consentimiento para acciones de cuenta |
| `claims/` | Revisión de notas y reclamaciones nativas |
| `defi/` | Contrato de interacción con posiciones DeFi |
| `portfolio/` | Estado de posiciones, cartera y observaciones de tokens |
| `withdrawals/` | Revisión, reanudación y acciones de retirada wrapped |
