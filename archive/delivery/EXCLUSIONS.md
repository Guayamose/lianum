# Exclusiones de esta entrega

Incluye el código fuente actual completo de su lista autoritativa y referencias de documentación, contratos, circuitos, pruebas y propuestas guardadas. No incluye:

- claves privadas, contraseñas, seeds, cápsulas privadas de recuperación, credenciales o transacciones privadas firmadas
- el estado vivo perdido de las redes locales ni sus bases de datos
- node_modules, runtimes grandes, binarios, CRS, witnesses ni el volumen completo de artefactos criptográficos generados
- copias repetidas completas de cada estado intermedio; se conservan la lista actual y evidencia de restauración
- resultados inexistentes: auditoría externa, certificaciones, ejecución de producción o aceptación total de las siete redes

Los artefactos públicos grandes se conservan en respaldos independientes cuando están disponibles. La reconstrucción requiere dependencias y pines documentados; no es un ejecutable autocontenido. El código puede reutilizar pruebas/keys públicas existentes, pero éstas no recuperan identidades privadas perdidas.

Para evitar duplicados, las copias de referencia idénticas se remiten a su archivo conservado mediante REFERENCE-DEDUPLICATION.json. También se omiten parches voluminosos de transacciones históricas intermedias: el código actual exacto y su comprobación permanecen incluidos. No falta ningún archivo de la lista autoritativa actual.
