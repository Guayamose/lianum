# Commands and Tools

[Documentation](../docs/README.md) · [Architecture](../docs/ARCHITECTURE.md) · [Validation](../docs/VALIDATION.md)

| Directory | Function |
| --- | --- |
| `development/` | Environment preparation, compatibility and everyday commands |
| `wallet/` | Compilation, preparation and validation of the wallet |
| `engine/` | Audits, demos, diagnostics and engine flows |
| `protocol/` | Compatibility tools for the retained protocol generation |
| `documentation/` | Branded SVG artwork, PNG rendering and documentation checks |
| `components/` | Workers and launchers of circuit components |
| `compilers/` | Consumer Solidity compiler configuration |

Use `./dev help` for the executable command catalog, `./dev check` for bounded repository checks and `./dev node path/to/module.mjs` for a specific module. The [development guide](../docs/DEVELOPMENT.md) explains artwork regeneration and documentation validation.
