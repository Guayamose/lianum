# Commands and Tools

| Directory | Function |
| --- | --- |
| `development/` | Environment preparation, compatibility and everyday commands |
| `wallet/` | Compilation, preparation and validation of the wallet |
| `engine/` | Audits, demos, diagnostics and engine flows |
| `protocol/` | Tools from the previous generation of protocol |
| `components/` | Workers and launchers of circuit components |
| `compilers/` | Consumer Solidity Compilers Configuration |

Usa `npm run dev`, `npm run check` and `npm test` from the root. The specific modules are executed with `./dev node ruta/al/modulo.mjs`.
