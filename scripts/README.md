# Comandos y herramientas

| Carpeta | Función |
| --- | --- |
| `development/` | Preparación del entorno, compatibilidad y comandos cotidianos |
| `wallet/` | Compilación, preparación y validación de la wallet |
| `engine/` | Auditorías, demos, diagnóstico y flujos del motor |
| `protocol/` | Herramientas de la generación anterior del protocolo |
| `components/` | Workers y lanzadores de componentes de circuito |
| `compilers/` | Configuración de compiladores Solidity por consumidor |

Usa `npm run dev`, `npm run check` y `npm test` desde la raíz. Los módulos
específicos se ejecutan con `./dev node ruta/al/modulo.mjs`.
